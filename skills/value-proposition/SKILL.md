# Value Proposition

Turn what a product does into a single promise a specific buyer believes and can act on — the message everything else hangs off.

## When to use this
- The user needs a crisp value proposition for a homepage hero, deck, or campaign.
- Messaging feels generic, feature-led, or doesn't say who it's for.
- A new audience or segment needs its own framing.

## When not to use this
- Category and competitive frame aren't settled → run `positioning-statement` first; a value prop is downstream of positioning.
- The user wants the full message hierarchy → use `messaging-framework`.

## What you need
Pull from `brand-product-context` if available: the ICP/segment, the product's core capability, the top customer pain, the differentiator, and proof (metrics, outcomes). If missing, ask the user for three things: who it's for, the main problem solved, and one proof point.

## Method
1. **Name the buyer and the job.** State the specific audience and the job they hire the product to do. "For teams" fails; "for seed-stage B2B founders running their own marketing" works.
2. **Lead with the outcome, not the feature.** Write the promise as the result the buyer gets, then attach the mechanism: outcome → because → mechanism.
3. **Make it defensible with proof.** Attach 2–3 proof points (a metric, an outcome, a credible mechanism). No proof means it's a slogan.
4. **Draft the one-liner** in this shape: *For [buyer] who [need], [product] is the [category] that [outcome], because [mechanism].* Then write a shorter hero version (≤ 15 words).
5. **Pressure-test.** Could a competitor paste the same line? If yes, sharpen the differentiator. Would the buyer recognize their own words? If no, rewrite in their language.
6. **Make variants** for the top 1–2 segments if they differ materially.

## Output
Return:
- **Value proposition (hero):** one line, ≤ 15 words.
- **Full statement:** the For/who/is-the/that/because sentence.
- **Proof points:** 2–3 bullets.
- **Variants:** per segment, if applicable.
- **Why it holds:** one line on the differentiator that makes it hard to copy.

## Defensibility check
Before delivering, confirm it names a specific buyer, leads with an outcome, includes real proof, and a competitor couldn't paste the same line. If any fail, revise — a value prop the user can't defend is worse than none.
