# Recipes: vendor data in, a verdict out

Vendor MCP servers give your agent data: deals, sessions, search volumes. They don't tell you what the numbers mean. AAJ's engines do that part, and they compute it the same way every time, so the agent doesn't have to estimate. Each recipe connects one vendor server to one engine. It gives you a prompt to paste, shows which vendor field goes into which engine input, and lists what to check before you trust the result.

| Recipe | Vendor data | Engine | What you get |
|---|---|---|---|
| [HubSpot deals into the forecast](hubspot-to-pipeline-forecast.md) | HubSpot MCP server: open deals with their probabilities and close dates, the deals closed won this quarter, and closed won and lost counts | `pipeline-and-forecast` | What has closed won, a weighted forecast, commit against best case, coverage of what is left against your win rate, the gap, the chance of reaching the target and the one lever to pull |
| [HubSpot contacts into the funnel leak finder](hubspot-to-funnel-leak.md) | HubSpot MCP server: the date each contact entered each lifecycle stage | `funnel-leak-finder` | The funnel for two periods, counted by the engine, and the stage that cost the most wins |
| [GA4 results into significance](ga4-to-ab-test-significance.md) | Google Analytics MCP server: sessions and key events by variant | `ab-test-significance` | Sample size before the test; lift, p-value, confidence interval and a verdict after it |
| [GA4 traffic sources into AI referral share](ga4-to-ai-referral-share.md) | Google Analytics MCP server: sessions and key events by source and medium | `ai-referral-share` | Each AI assistant's share of sessions and key events, and whether its visits really convert differently from the rest |
| [Keyword data into a pSEO decision](keyword-data-to-programmatic-seo.md) | Ahrefs or Semrush MCP server: volume and difficulty for your target queries | `aaj-programmatic-seo` | Whether a template-page build pays back, through an indexation and ranking funnel |
| [Search Console data into content decay](search-console-to-content-decay.md) | Google's Search Analytics API, or a Search Console export: clicks, impressions and average position across two periods | `content-decay` | Which pages are decaying, losing snippets or hitting seasonal drops; refresh priorities ranked by clicks lost; and page-one CTR tests |
| [Search Console queries into search demand](search-console-to-search-demand.md) | Google's Search Analytics API, or a Search Console export: clicks, impressions and average position for each query and page | `search-demand-reader` | Demand by intent, topics you appear for on page two or worse, queries split across your own pages, branded share |
| [Stripe data into unit economics](stripe-to-unit-economics.md) | Stripe MCP server: MRR. Stripe's Billing overview: active subscribers and subscriber churn rate | `unit-economics` | Gross-margin LTV, CAC payback, LTV:CAC ratio, and a verdict against David Skok and Bessemer reference points |
| [Google Ads data into a paid search audit](google-ads-to-paid-search-audit.md) | Google Ads MCP server: campaigns, search terms and landing pages for one period | `paid-search-account-audit` | Account, brand and non-brand CPA; spend that produced nothing; starved winners; terms to negate and winners to add; one fix list ranked blocking-first |
| [Google Ads test results into the creative test reader](google-ads-to-ad-creative-test.md) | Google Ads MCP server: impressions, clicks, conversions and cost for each experiment arm or ad | `ad-creative-testing` | Each variant's rate and interval, the lift, a corrected significance test, and no winner when delivery was uneven |

Every recipe runs with the engines either installed (`npx skills add sarojkjha/aaj-marketing-skills`) or hosted (`https://mcp.aajconsult.com/mcp`, no install). The engines make no network calls, and the hosted server keeps no copy of what you send it; your agent's model provider still sees the numbers you give the agent ([details](../README.md#what-happens-to-your-data)).

Nothing here ranks or endorses a vendor. If you use another CRM, analytics, ads or keyword tool, the same mapping tables apply. Only the connection steps change.
