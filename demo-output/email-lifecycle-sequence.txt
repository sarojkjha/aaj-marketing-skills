  1. Onboarding / activation
     Job:     Get the user to first value, then to habit
     Audience: new signups
     Cost of not having it: Signups that never activate churn silently and are rarely recoverable.

  2. Welcome
     Job:     Confirm the decision, set expectations, drive first meaningful action
     Audience: new signups
     Cost of not having it: Highest-intent moment of the whole relationship, unused.

  3. Expansion / upgrade
     Job:     Move users to higher value when usage justifies it
     Audience: active users at a threshold
     Cost of not having it: NRR depends on expansion. Without it, growth needs new logos.

  4. Win-back
     Job:     Recover lapsed users before the account is gone
     Audience: lapsed / inactive users
     Cost of not having it: Recovering a lapsed user is usually far cheaper than acquiring one.

  5. Engagement / nurture
     Job:     Stay useful between purchases; deepen usage
     Audience: active users
     Cost of not having it: The list goes cold, so every later send underperforms.

  6. Sunset / re-permission
     Job:     Cleanly exit the disengaged so deliverability holds
     Audience: long-inactive users
     Cost of not having it: Sending to dead addresses degrades deliverability for everyone else.
